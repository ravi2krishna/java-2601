    -> Switch Statement 

        -> A switch statement is used to select one block of code 
        from multiple options based on a single value.

        -> Syntax

            switch(expression) {
                case value1:
                    // statement
                    break;
                case value2:
                    // Statements
                    break;
                    .
                    .
                    .
                default:
                    // Statements
                    break;
            }


        Feature	        switch	                    if-else
        Condition type	Only equality (==)	        Any condition (>, <, &&, etc.)
        Readability	    Cleaner for many values	    Becomes messy with many conditions
        Performance	    Slightly faster 	        Slower if many checks
        Use case	    Fixed values	            Complex logic 

        -> NOTE: You should use switch when you are Comparing one variable against fixed values 

            -> Menu Options 
            -> Status Codes 
            -> Roles 
            -> Days 

        -> NOTE: Don't use switch when you want to do 

            -> if (age > 18 and salary > 25000) - this CANNOT be done using switch 

        -> NOTE: If you forget break, java will execute all cases after match,
        this is called as Fall Through 

        -> In Modern Java (17 Onwards) switch is more Readable

    -> while loop

        -> Used when you DON'T know number of Iterations / Repetitions in advance

            init;

        -> Similar to while, but runs the code at least once, before checking the condition

class - 9
==========

    -> Variable stores data

    -> Types Of Variables 

        -> Instance Variables

        -> Local Variables

        -> Static Variables (Class / Global)



    -> Instance Variables

        -> Created inside the class and outside the method, without static keyword

        -> Instance: Object of an class 

        -> Instance Variables are always associated with Object

        -> Memory is allocated when object is created 

        -> Instance Variables have default values, if not initialized

    
    -> Local Variables

        -> Created inside the method, blocks and constructors 

        -> Local Variables are used for Temporary Calculations 

        -> Once execution is completed, Local Variables becomes obsolete 

        -> Local Variables should be initialized 

    
    -> Static Variables

        -> Created inside the class and outside the method, with static keyword

        -> Static Variables are always associated with Class 

        -> Used for Fixed / Static Values (Common Data)

        -> Static Variables have default values, if not initialized

        -> To Access Static Variable we use Class i.e ClassName.staticVariable  



    Type        Declared                Belongs To         Default Values       Memory
    local       method/blocks           method/blocks      Must initialize      Stack
    instance    class(no static)        objects            Yes                  Heap
    static      class(with static)      class              Yes                  MethodArea


-> Constructors 

    -> Method: Block of code that performs some task 

    -> Constructor: Block of code that initializes Default Values (Special Task)

    -> NOTE: Constructor is a special method that is Automatically called, when object is created

    -> Normal Methods (Instance Methods) what we learnt so far cannot be called 
    Automatically, we need to call them using object 

        -> Create Object 
        -> Call Method 

        -> Example: showEmployeeInfo() 

    -> Constructors are used mainly for 

        -> initialize default values 

        -> set up start up values 

    -> NOTE: 

        -> Constructor Name should always be Class Name Only, unlike methods 

        -> Constructors will not have return types

        -> Automatically invoked, unlike methods 

    -> Types Of Constructors

        -> Default Constructor (Implicit Constructor)

            -> Used to initialize all objects with same data 

        -> Parameterized Constructor (Explicit Constructor)

            -> Used to initialize different objects with different data

class - 9
==========

    -> Constructor overloading in Java is a technique that allows a class 
    to have more than one constructor with the same name, 
    provided they have different parameter lists. 
    
    -> This enables you to initialize objects in various ways depending 
    on the data available at the time of creation.

    -> Based On 

        -> Number Of Parameters

            -> Number of parameters: Having a different count of arguments (e.g., zero-arg vs. two-arg).

        -> Type Of Parameters

            -> Type of parameters: Having arguments of different data types (e.g., int vs. String).

        -> Order Of Parameters

            -> Order of parameters: Having the same types but in a different sequence (e.g., (int, String) vs. (String, int))


    -> this()

        -> this() is a special syntax used to call one constructor from another within the same class. 
        This practice is known as "constructor chaining" and is primarily used to 
        reduce code duplication when you have multiple overloaded constructors.

        -> this vs. this() 
            
            -> While they look similar, they serve different purposes:
            
                -> this (Keyword): A reference variable that refers to the current object. 
                It is used to access instance variables (e.g., this.name = name) 
            
                -> this() (Call): A specific syntax for invoking constructors
