        -> Java is a memory-safe language

            -> Java manages memory automatically using JVM + Garbage Collector 

            -> Automatically remove "Unused Data"

            -> Java Automatically Cleans Up Unused Objects / Data from memory i.e RAM 

                String product = "iphone";
                int price = 120000
                double rating = 4.7;
                System.out.println(product)
                System.out.println(price)

            -> Java Cleans Up rating memory as it's never used in the program 

            -> When an object is no longer used, Garbage Collector removes it Automatically 

            -> NOTE: If we use C/C++, you need to manually clean up Unused memory.
